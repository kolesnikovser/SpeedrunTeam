# SpeedrunTeam — Панель управления скоростными забегами

## ⚡ О проекте

**SpeedrunTeam** — это высокопроизводительное полностековое веб-приложение для координации и мониторинга команд в скоростных соревнованиях (спидранах). 

Проект сочетает в себе:
- **Backend:** Node.js + Express с реляционной базой данных SQLite на WebAssembly (через `sql.js` для кроссплатформенной переносимости без бинарных компиляторов).
- **Frontend:** Современный, премиальный интерфейс на Vite + React 18 + TypeScript с использованием стеклянного дизайна (glassmorphic panels), гармоничных градиентов и плавной анимации.
- **Тестирование:** Полный набор Jest-тестов, адаптированных для работы с нативными модулями ES Modules (ESM).
- **Docker:** Легковесный многоэтапный Docker-контейнер и `docker-compose.yml` для мгновенного деплоя всей системы на едином порту.

## 🛠️ Локальный запуск и разработка

### Шаг 1: Установка зависимостей
Установите необходимые пакеты для бэкенда и фронтенда:
```bash
# Установка зависимостей бэкенда
npm install

# Переход во фронтенд и установка зависимостей
cd frontend
npm install
cd ..
```

### Шаг 2: Сборка фронтенда
Скомпилируйте исходный код React в высокооптимизированный продакшн-пакет:
```bash
cd frontend
npm run build
cd ..
```
*Примечание: Собранные файлы будут помещены в `frontend/dist`.*

### Шаг 3: Запуск сервера
Запустите бэкенд, который автоматически инициализирует SQLite базу данных `data.db` и будет обслуживать как REST API, так и собранный фронтенд:
```bash
npm start
```
По умолчанию приложение запустится на **`http://localhost:3000`**.  
Если вы хотите переопределить порт (например, из-за конфликта портов), используйте переменную окружения `PORT`:
```bash
# Для Windows (cmd)
set PORT=3005 && npm start

# Для macOS/Linux (bash)
PORT=3005 npm start
```

## 🧪 Запуск модульных тестов

В проекте настроена нативная поддержка ES-модулей в тестовой среде Jest. Чтобы запустить тесты базы данных, выполните:
```bash
npm test
```

## 🐳 Развёртывание в Docker

Мы используем оптимизированный двухэтапный Dockerfile, который автоматически собирает фронтенд внутри временного контейнера сборщика, а затем упаковывает его в финальный образ с Node.js. Это гарантирует отсутствие необходимости предустановки Node.js на хосте.

Запустите контейнер одной командой:
```bash
docker compose up --build
```
После успешного запуска приложение и API будут доступны по адресу: **`http://localhost:3000`**.  
База данных автоматически монтируется во внешний Docker volume `db-data` для сохранения ваших записей при перезапусках.

## 📝 Сценарии использования
1. **Создание команды:** Перейдите на вкладку **Команды**, введите уникальное название и нажмите «Добавить».
2. **Фиксация результатов:** Перейдите во вкладку **Записи забегов**, выберите вашу команду из списка, укажите достигнутое время в формате `ЧЧ:ММ:СС.мм` (например, `01:14:28.45`), укажите дату и сохраните результат.
3. **Редактирование и удаление:** Вы можете легко изменять названия команд и результаты забегов прямо в интерактивных таблицах.
